How to format

  • # TitleDocument title (first line if no # is used)
  • ## SectionSection heading with underline
  • 1. Question textNumbered question — "1)" also works
  • A) Option oneMultiple-choice options, one per line — or inline "A) ... B) ... C) ..."
  • Answer: textShown inline (Revision) or moved to Answer Key (Exam)
  • Note: textHighlighted side note
  • Key Term: textSmall badge, then a line below for its definition
  • Key Fact: textHighlighted fact box

Leave a blank line between blocks. Anything else becomes plain paragraph text.

Quick PDF

Fast export — image-based PDF

  • Pixel-perfect match of the current preview

High Quality PDF

Slower export — sharp, selectable text

  • Real, selectable and searchable PDF text
  • Vector-sharp borders, decorations and lines at any zoom
  • Requires the local QFormat PDF service to be running
High Quality PDF renders your document in headless Chromium on a small local service. If the export fails, make sure it's running (see qformat-pdf-service — npm install && npm start).
